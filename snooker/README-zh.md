# 如何游玩斯诺克地铁 (Snooker Tubey) 及使用追踪器应用

## 什么是斯诺克地铁？
斯诺克地铁是传统斯诺克的变体，它将击球技巧与对伦敦标志性交通网络地理知识的了解结合在一起。玩家必须根据官方地铁图，报出一个符合所击落彩球颜色的有效地铁 (Underground)、地上铁 (Overground) 或伊丽莎白线 (Elizabeth Line) 站名。

## 如何游玩

### 1. 基本玩法结合
* 按照标准斯诺克规则进行：击落红球，然后击落彩球，循环往复。
* 击落彩球后，必须立即报出一个符合该颜色线路规则的伦敦地铁站。
* 每个站点在每局游戏中只能使用一次。
  * 玩家有 **10 秒钟**时间报出站点。

### 2. 颜色与线路对应关系
| 球体颜色 | 主要线路 | 备用线路 |
| :--- | :--- | :--- |
| **红色** | 中央线 (Central) | 大都会线 (Metropolitan) & Weaver |
| **黄色** | 环线 (Circle) | Lioness |
| **绿色** | 区域线 (District) | Suffragette |
| **棕色** | 贝克卢线 (Bakerloo) | Windrush |
| **蓝色** | 皮卡迪利线 (Piccadilly) | 维多利亚线 (Victoria) |
| **粉色** | 汉默史密斯及城市线 (H&C) | 伊丽莎白线 (Elizabeth) |
| **黑色** | 北线 (Northern) | 朱比利线 (Jubilee) |

* **换乘站:** 服务多条线路的站点可以被计为与其相关的任何线路。

### 3. 站点使用规则
* 错误报站会导致罚 4 分**或**对手获得手中球 (Ball-in-hand)，并结束回合。

### 4. 进阶选项
* **难度分级:** 休闲 (无限次)，中级 (2次)，高级 (1次)。
* **地上铁百搭牌:**
  * 每局游戏一次，可报出一个**伦敦地上铁 (Overground)** 站点以**解锁一个已使用的站点**。

## 追踪器应用
网络辅助应用，支持离线 PWA。本地使用 `pnpm start` 运行于 3000 端口。
