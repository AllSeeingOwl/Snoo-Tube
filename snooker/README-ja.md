# スヌーカートゥービーの遊び方とトラッカーアプリの使い方

## スヌーカートゥービーとは？
スヌーカートゥービーは、伝統的なスヌーカーに、ロンドンの象徴的な交通機関ネットワークの地理的知識を組み合わせたユニークなゲームです。プレイヤーは、公式の路線図に基づき、ポケットに入れたボールの色に対応する有効なロンドン地下鉄（チューブ）、オーバーグラウンド、またはエリザベス線の駅名を宣言する必要があります。

## 遊び方

### 1. 基本的なゲームプレイ
* 標準的なスヌーカーと同じようにプレイします。赤いボールをポケットに入れ、次にカラーボールを入れ、これを繰り返します。
* カラーボールをポケットに入れた後、プレイヤーは以下のルールに従って、その色に割り当てられた路線に一致するロンドンの駅名をすぐに宣言しなければなりません。
* 各駅は1ゲームにつき1回のみ使用可能です（ティアリングやワイルドルールで変更されない限り）。
  * 有効な駅は、公式のTfL路線図に掲載されており、色のルールに一致する必要があります。
  * プレイヤーはカラーボールをポケットに入れてから**10秒以内**に駅名を宣言する必要があります。失敗すると、そのショットのポイントは没収され、ターンは終了します。

### 2. 色と路線の割り当て
| ボールの色 | 主要路線 | 予備路線 |
| :--- | :--- | :--- |
| **赤** | セントラル | メトロポリタン & ウィーバー |
| **黄** | サークル | ライオネス |
| **緑** | ディストリクト | サフラジェット |
| **茶** | ベーカールー | ウィンドラッシュ |
| **青** | ピカデリー | ヴィクトリア |
| **ピンク** | ハマースミス＆シティー | エリザベス |
| **黒** | ノーザン | ジュビリー |

* **オーバーグラウンド路線:** 柔軟性を高めるため、複数の色に分散して割り当てられています。
* **乗換駅:** 複数の路線が乗り入れる駅は、ポケットに入れた色と路線が一致していれば、その駅が関連する「どの」路線としてカウントしても構いません。

### 3. 駅の使用ルール
* 駅名を正しく宣言すると、その駅は「ロック」され、再利用できなくなります。
* **有効な駅の条件:**
  * 公式のTfL路線図で現在利用可能であること。
  * ゾーン1〜6内であること（オプションのローカルルール）。
  * ポケットに入れたボールに関連付けられた色・路線と一致していること。
* **不正な駅の宣言**の場合：
  * 4ポイントのペナルティ **または**
  * 相手のボールインハンド（開始前にローカルルールとして決定）。
  * プレイヤーのターンは終了します。

### 4. 高度なオプション
* **駅の再利用ティアリング:**
  * *カジュアル:* 駅の再利用が可能。
  * *中級:* 各駅は2回まで使用可能。
  * *上級:* 各駅1回のみ。
* **駅切れルール:**
  * 有効な未使用の駅が残っていない場合、予備路線の駅を使用するか、必要な路線が乗り入れている乗換駅を宣言できます。
* **オーバーグラウンドワイルドカード機能（オプション）:**
  * 1ゲームにつき1回、*任意の*カラーボールをポケットに入れた直後に、**ロンドンオーバーグラウンド**路線の駅を宣言して**以前に使用された駅を1つアンロック**できます。
* **スコアリングモディファイア（オプション）:**
  * ゾーン1の駅を宣言すると+1ボーナスポイント。
  * 3つ以上の路線が乗り入れる乗換駅を宣言すると+2ボーナスポイント。

## トラッカーアプリの使い方
**スヌーカートゥービートラッカー**は、プレイ中の駅を記録するコンパニオンアプリです。
PWAとして構築されており、オフラインで使用できます。ローカルで実行するには `pnpm start` を使用し、`http://localhost:3000/` にアクセスします。
