# Spielanleitung für Snooker Tubey & Nutzung der Tracker-App

## Was ist Snooker Tubey?
Snooker Tubey ist eine Variante des traditionellen Snookers, die das Geschick am Queue mit dem geografischen Wissen über Londons ikonisches Verkehrsnetz verbindet. Spieler müssen eine gültige Station der Underground, Overground oder Elizabeth Line nennen, die mit der Farbe der versenkten Kugel übereinstimmt.

## Spielanleitung

### 1. Grundlegende Spielintegration
* Spielablauf wie beim Standard-Snooker: Rot versenken, dann eine Farbe, wiederholen.
* Nennen Sie nach einer Farbe eine Londoner Station, die zur Linie der Farbe passt.
* Stationen können nur einmal pro Spiel verwendet werden.
  * Sie haben **10 Sekunden** Zeit für die Nennung.

### 2. Farb-zu-Linien-Zuweisungen
| Kugelfarbe | Primäre Linie(n) | Backup Linie(n) |
| :--- | :--- | :--- |
| **Rot** | Central | Metropolitan & Weaver |
| **Gelb** | Circle | Lioness |
| **Grün** | District | Suffragette |
| **Braun** | Bakerloo | Windrush |
| **Blau** | Piccadilly | Victoria |
| **Pink** | Hammersmith & City | Elizabeth |
| **Schwarz** | Northern | Jubilee |

* **Umsteigestationen:** Zählen für alle Linien, die an der Station halten.

### 3. Regeln
* Ein falscher Aufruf bedeutet 4 Strafpunkte ODER "Ball-in-hand" für den Gegner und das Ende des Zuges.

### 4. Erweiterte Optionen
* **Schwierigkeit:** Casual (unbegrenzt), Intermediate (2 Nutzungen), Advanced (1 Nutzung).
* **Overground Joker:**
  * Einmal pro Spiel können Sie eine **London Overground** Station nennen, um eine **zuvor verwendete Station freizuschalten**.

## Tracker-App
Die Web-App hilft beim Tracking und funktioniert offline als PWA.
Lokal starten mit `pnpm start` (Port 3000).
