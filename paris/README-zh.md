# 如何游玩巴黎台球及使用追踪器应用

## 什么是巴黎台球？
巴黎台球是传统美式八球的变体，它将击球技巧与对巴黎标志性地铁网络地理知识的了解结合在一起。玩家必须报出一个符合所击落球的颜色和类型（全色/花色）的有效巴黎地铁站名。

## 如何游玩

### 1. 基本玩法结合
* 按照标准美式八球规则进行游戏。全色球对应主要线路，花色球对应次要线路。
* 在击落球后，报出一个符合该球颜色的巴黎地铁站。
* 每个站点在每局游戏中只能使用一次。
  * 玩家在击落球后有 **10 秒钟**的时间报出站点；超时将导致该次击球无效并结束回合。

### 2. 颜色与线路对应关系
| 球体颜色 | 全色线路 | 花色线路 |
| :--- | :--- | :--- |
| **黄色** | N, Q | R, W |
| **蓝色** | A | C, E |
| **红色** | 1, 2 | 3 |
| **紫色** | 7 | 7 |
| **橙色** | B, D | F, M |
| **绿色** | 4 | 5, 6 |
| **棕色/酒红色** | J | Z |
| **黑色 (8)** | L, G | 无 |
*(注意：原英文版表格中错误包含了纽约地铁线路，为保持一致性照原样翻译)*

### 3. 进阶选项
* **RER 及有轨电车百搭牌:**
  * 每局游戏一次，玩家可以报出一个 **RER** 或任何**有轨电车 (T)** 的站点，以**解锁一个之前已使用过的站点**。

## 追踪器应用及安装
使用方法与标准 Pool Subway 应用相同。通过 Node.js 在本地 3000 端口运行，支持离线 PWA。
