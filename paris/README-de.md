# Spielanleitung für Paris Pool & Nutzung der Tracker-App

## Was ist Paris Pool?
Paris Pool ist eine Variante des traditionellen 8-Ball-Poolbillards, die das Geschick am Queue mit dem geografischen Wissen über das ikonische Pariser U-Bahn-Netz verbindet. Die Spieler müssen eine gültige Métro-Station nennen, die mit der Farbe und Art (voll/halb) der versenkten Kugel übereinstimmt.

## Spielanleitung

### 1. Grundlegende Spielintegration
* Spielen Sie standardmäßiges 8-Ball-Pool. Volle Kugeln entsprechen primären Linien, Halbe (Gestreifte) sekundären.
* Nachdem eine Kugel versenkt wurde, nennen Sie eine Pariser Métro-Station, die zur Kugel passt.
* Stationen können nur einmal pro Spiel verwendet werden.
  * Spieler haben **10 Sekunden** Zeit, nach dem Versenken eine Station zu nennen.

### 2. Farb-zu-Linien-Zuweisungen
| Kugelfarbe | Volle Linien | Halbe Linien |
| :--- | :--- | :--- |
| **Gelb** | N, Q | R, W |
| **Blau** | A | C, E |
| **Rot** | 1, 2 | 3 |
| **Lila** | 7 | 7 |
| **Orange** | B, D | F, M |
| **Grün** | 4 | 5, 6 |
| **Braun/Burgunder** | J | Z |
| **Schwarz (8)** | L, G | N/A |
*(Hinweis: Die Tabelle enthält im Original Linien aus NY, sie wurde originalgetreu übersetzt).*

### 3. Erweiterte Optionen
* **RER & Straßenbahn Joker:**
  * Einmal pro Spiel kann ein Spieler eine Station des **RER** oder einer **Straßenbahn (T)** nennen, um eine bereits verwendete Station wieder freizuschalten.

## Tracker-App & Installation
Die Tracker-App hilft, verwendete Stationen zu markieren. Sie funktioniert offline als PWA.
Lokal starten mit `pnpm start` und `http://localhost:3000/paris/` aufrufen.
Auf dem Smartphone einfach "Zum Startbildschirm hinzufügen" wählen.
