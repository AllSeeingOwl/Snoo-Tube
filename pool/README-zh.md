# 如何游玩台球地铁及使用追踪器应用

## 什么是台球地铁？
台球地铁是传统美式八球的变体，它将击球技巧与对纽约标志性地铁网络地理知识的了解结合在一起。玩家必须报出一个符合所击落球的颜色和类型（全色/花色）的有效纽约地铁站名。

## 如何游玩

### 1. 基本玩法结合
* 按照标准美式八球规则进行游戏。全色球对应主要线路，花色球对应次要线路。
* 在击落球后，报出一个符合该球颜色的纽约地铁站。
* 每个站点在每局游戏中只能使用一次。
  * 玩家在击落球后有 **10 秒钟**的时间报出站点；超时将导致该次击球无效并结束回合。

### 2. 颜色与线路对应关系
| 球体颜色 | 全色线路 | 花色线路 |
| :--- | :--- | :--- |
| **黄色** | N, Q | R, W |
| **蓝色** | A | C, E |
| **红色** | 1, 2 | 3 |
| **紫色** | 7 | 7 |
| **橙色** | B, D | F, M |
| **绿色** | 4 | 5, 6 |
| **棕色/酒红色** | J | Z |
| **黑色 (8)** | L, G | 无 |

### 3. 进阶选项
* **斯塔滕岛及穿梭线 (Shuttles) 百搭牌:**
  * 每局游戏一次，玩家可以报出一个**斯塔滕岛铁路**或任何**穿梭线 (S)**的站点，以**解锁一个之前已使用过的站点**。

## 追踪器应用及安装
应用功能包括搜索、难度分级和记录站点使用情况，支持离线使用（PWA）。
在本地终端运行 `pnpm start` 然后访问 `http://localhost:3000/pool/`。
在手机端，只需在浏览器中选择“添加到主屏幕”即可。
