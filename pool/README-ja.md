# プールサブウェイの遊び方とトラッカーアプリの使い方

## プールサブウェイとは？
プールサブウェイは、伝統的なエイトボールプールに、ニューヨークの象徴的な地下鉄ネットワークの地理的知識を組み合わせたユニークなゲームです。プレイヤーは、ポケットに入れたボールの色と種類（ソリッド／ストライプ）に対応する有効なニューヨーク地下鉄の駅名を宣言する必要があります。

## 遊び方

### 1. 基本的なゲームプレイ
* 標準的なエイトボールプールをプレイします。ソリッドボール（単色）は主要路線に、ストライプボール（縞模様）は二次路線に対応します。
* ボールをポケットに入れた後、ボールの色のマッピングに一致するニューヨークの地下鉄駅名を宣言します。
* 各駅は1ゲームにつき1回のみ使用可能です（ティアリングやワイルドルールで変更されない限り）。
  * 有効な駅は、公式のニューヨーク地下鉄路線図に掲載されており、色のルールに一致する必要があります。
  * プレイヤーはカラーボールをポケットに入れてから**10秒以内**に駅名を宣言する必要があります。失敗すると、そのショットのポイントは没収され、ターンは終了します。

### 2. 色と路線の割り当て
| ボールの色 | ソリッド（単色） | ストライプ（縞模様） |
| :--- | :--- | :--- |
| **黄** | N, Q | R, W |
| **青** | A | C, E |
| **赤** | 1, 2 | 3 |
| **紫** | 7 | 7 |
| **オレンジ** | B, D | F, M |
| **緑** | 4 | 5, 6 |
| **茶/バーガンディ** | J | Z |
| **黒 (エイトボール)** | L, G | 該当なし |

* **乗換駅:** 複数の路線が乗り入れる駅は、ポケットに入れた色と路線が一致していれば、その駅が関連する「どの」路線としてカウントしても構いません。

### 3. 駅の使用ルール
* 駅名を正しく宣言すると、その駅は「ロック」され、再利用できなくなります（ワイルドルールや駅の再利用ティアリングで変更されない限り）。
* **有効な駅の条件:**
  * 公式のニューヨーク地下鉄路線図で現在利用可能であること。
  * ポケットに入れたボールに関連付けられた色・路線と一致していること（セクション2を参照）。
* **不正な駅の宣言**（例：間違った路線、既に使用済み、地図にない、時間切れ）の場合：
  * 標準のプールファウル（例：相手のボールインハンド）となります。
  * プレイヤーのターンは終了します。

### 4. 高度なオプション
* **駅の再利用ティアリング:**
  * *カジュアル:* 駅の再利用が可能です。
  * *中級:* 各駅は1ゲームにつき2回まで使用できます。
  * *上級:* 1ゲームにつき各駅1回のみの厳格な使用制限。
* **駅切れルール:**
  * 必要な路線で有効な未使用の駅が残っていないとプレイヤーが判断した場合：
    * 必要な路線が乗り入れている乗換駅を宣言することができます（たとえその駅が主に他の路線で知られている場合でも）。
    * 相手から異議を唱えられ、間違っていた場合は標準のペナルティが適用されます。正しければプレイを続行します。
* **スタテンアイランド鉄道＆シャトルワイルドカード機能（オプション）:**
  * 1ゲームにつき1回、*任意の*カラーボールをポケットに入れた直後に、プレイヤーは**スタテンアイランド鉄道**または任意の**シャトル（S）**路線の駅を宣言することを選択できます。
  * ワイルドカードの駅宣言が有効な場合、**以前に使用された駅を1つアンロック**し、ゲームの後半でどちらのプレイヤーも再び宣言できるようにします。プレイヤーはどの駅をアンロックするかを宣言する必要があります。
  * このワイルドカードの宣言は、そのショットにおける、ポケットに入れた色に一致する駅を指名するという標準的な要件の代わりとなります。

## トラッカーアプリの使い方

**プールサブウェイトラッカー**は、プレイ中の駅を記録するのに役立つウェブベースのコンパニオンアプリです。

### 主な機能
- **検索＆フィルタリング:** 駅を名前、路線、または色で瞬時に検索します。
- **難易度ティア:** 上級（1回使用）、中級（2回使用）、カジュアル（使用無制限）のルールをシームレスに切り替えます。アプリはティアのルールに基づいて駅を自動的にロックします。
- **駅のロック:** 有効な駅が宣言されたら、リストで見つけて「Record Use（使用を記録）」をクリックします。ティアのルールに基づいて自動的にロックされ、グレーアウトされます。
- **スタテンアイランドワイルドカード:** 組み込みのワイルドカードボタンを使用して、以前に使用した駅を簡単にアンロックできます。
- **オフラインサポート:** プログレッシブウェブアプリ（PWA）として構築されています。モバイルデバイスにインストールして、インターネット接続なしで使用できます。
- **データの永続化:** 現在のゲームの状態はデバイスのローカルストレージに自動的に保存されるため、ページを更新しても進行状況が失われることはありません。

## アプリのインストール方法

### パソコンでローカルで実行する
アプリは`.csv`ファイルのデータベースを読み込み、Service Workerを登録する必要があるため、ローカルウェブサーバーを介して実行する必要があります（単に`index.html`ファイルをダブルクリックすることはできません）。

Node.jsと`pnpm`がインストールされている場合、簡単にサーバーを起動できます：

1. ターミナル/コマンドプロンプトを開きます。
2. このプロジェクトのルートフォルダに移動します。
3. 次のコマンドを実行して依存関係をインストールします：
   ```bash
   pnpm install
   ```
4. 次のコマンドを実行してサーバーを起動します：
   ```bash
   pnpm start
   ```
   *（または `node server.js`）*
5. ウェブブラウザを開き、`http://localhost:3000/pool/` にアクセスします。

### オフラインで使用するためのモバイルへのインストール
このアプリをモバイルデバイスのホーム画面に追加できます。追加すると、ネイティブアプリのように動作し、インターネット接続がない場合でも完全に機能します。

#### iOS（Safari）の場合:
1. アプリをオンラインでホストするか（GitHub Pages、Netlify、Vercelなど）、iPhone/iPadのブラウザでホストされているURLにアクセスします。
2. 画面下部の**共有**ボタン（上向きの矢印がある四角形）をタップします。
3. 共有シートを下にスクロールし、**ホーム画面に追加**をタップします。
4. 名前を確認して**追加**をタップします。アプリアイコンがホーム画面に表示されます。

#### Android（Chrome）の場合:
1. アプリをオンラインでホストするか、AndroidデバイスのブラウザでホストされているURLにアクセスします。
2. 画面下部に「Pool Subwayをホーム画面に追加」するかどうかを尋ねるプロンプトが表示される場合があります。その場合はタップします。
3. プロンプトが表示されない場合は、右上隅の3点メニューアイコンをタップします。
4. **アプリをインストール** または **ホーム画面に追加** をタップします。
5. 画面の指示に従います。
