# Spielanleitung für Tokyo Pool & Nutzung der Tracker-App

## Was ist Tokyo Pool?
Tokyo Pool ist eine Variante des Standard-8-Ball-Poolbillards, die das Geschick am Queue mit dem geografischen Wissen über Tokios ikonisches Verkehrsnetz verbindet.

## Spielanleitung

### 1. Grundlegende Spielintegration
* Spielen Sie standardmäßiges 8-Ball-Pool. Volle Kugeln entsprechen primären Linien, Halbe Kugeln (Gestreift) entsprechen sekundären Linien.
* Nachdem jede Kugel versenkt wurde, muss der Spieler sofort eine Station in Tokio nennen, die mit der/den zugewiesenen Linie(n) der Kugel übereinstimmt.
* Stationen können nur einmal pro Spiel verwendet werden.

### 2. Farb-zu-Linien-Zuweisungen
* **Gelb:** (Voll: Yurakucho) | (Halb: Keine)
* **Blau:** (Voll: Tozai) | (Halb: Mita)
* **Rot:** (Voll: Marunouchi) | (Halb: Oedo)
* **Lila:** (Voll: Asakusa) | (Halb: Hanzomon)
* **Orange:** (Voll: Ginza) | (Halb: Keine)
* **Grün:** (Voll: Chiyoda) | (Halb: Shinjuku)
* **Braun:** (Voll: Fukutoshin) | (Halb: Hibiya)
* **Schwarz (8):** Namboku

### 3. Erweiterte Optionen
* **Yamanote-Joker-Funktion:**
  * Einmal pro Spiel können Sie eine Station der Yamanote-Linie nennen, um eine zuvor verwendete Station freizuschalten.

## Nutzung der Tracker-App
Gleiche Nutzung wie bei der Standard-Pool-Subway-App. Lokal über Node.js auf Port 3000 ausführen.
