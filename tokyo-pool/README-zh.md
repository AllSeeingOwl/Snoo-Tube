# 如何游玩东京台球及使用追踪器应用

## 什么是东京台球？
东京台球是标准美式八球的变体，它将击球技巧与对东京标志性交通网络地理知识的了解结合在一起。

## 如何游玩

### 1. 基本玩法结合
* 按照标准美式八球规则进行游戏。全色球对应主要线路，花色球对应次要线路。
* 在每个球落袋后，玩家必须立即报出一个符合该球所分配线路的东京地铁站名。
* 每个站点在每局游戏中只能使用一次。

### 2. 颜色与线路对应关系
* **黄色:** (全色: 有乐町线) | (花色: 无)
* **蓝色:** (全色: 东西线) | (花色: 三田线)
* **红色:** (全色: 丸之内线) | (花色: 大江户线)
* **紫色:** (全色: 浅草线) | (花色: 半藏门线)
* **橙色:** (全色: 银座线) | (花色: 无)
* **绿色:** (全色: 千代田线) | (花色: 新宿线)
* **棕色:** (全色: 副都心线) | (花色: 日比谷线)
* **黑色 (8):** 南北线

### 3. 进阶选项
* **山手线百搭牌功能:**
  * 每局游戏一次，您可以报出一个山手线上的站点，以解锁一个之前已使用过的站点。

## 如何使用追踪器应用
使用方法与标准 Pool Subway 应用相同。通过 Node.js 在本地 3000 端口运行。
