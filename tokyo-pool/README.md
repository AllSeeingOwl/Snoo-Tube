# How to Play Tokyo Pool & Use the Tracker App

## What is Tokyo Pool?
Tokyo Pool is a twist on standard 8-ball pool, combining cue skill with geographic knowledge of Tokyo's iconic transport network.

## How to Play

### 1. Basic Gameplay Integration
* Play standard 8-ball pool. Solids map to primary lines, stripes map to secondary lines.
* After each ball is potted, the player must immediately call out a Tokyo station that matches the ball's assigned line(s).
* Stations can only be used once per game.

### 2. Colour-to-Line Assignments
* **Yellow:** (Solid: Yurakucho) | (Stripe: None)
* **Blue:** (Solid: Tozai) | (Stripe: Mita)
* **Red:** (Solid: Marunouchi) | (Stripe: Oedo)
* **Purple:** (Solid: Asakusa) | (Stripe: Hanzomon)
* **Orange:** (Solid: Ginza) | (Stripe: None)
* **Green:** (Solid: Chiyoda) | (Stripe: Shinjuku)
* **Brown:** (Solid: Fukutoshin) | (Stripe: Hibiya)
* **Black (8):** Namboku

### 3. Advanced Options
* **Yamanote Wildcard Feature:**
  * Once per game, you may call a station on the Yamanote line to unlock a previously used station.

## How to Use the Tracker App
Same usage as the standard Pool Subway app. Run locally via Node.js on port 3000.
