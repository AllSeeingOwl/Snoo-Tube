# Spielanleitung für Tokyo Snooker & Nutzung der Tracker-App

## Was ist Tokyo Snooker?
Tokyo Snooker ist eine Variante des traditionellen Snookers, die das Geschick am Queue mit dem geografischen Wissen über Tokios ikonisches Verkehrsnetz verbindet. Die Spieler müssen basierend auf dem offiziellen U-Bahn-Plan von Tokio eine gültige Station der Tokyo Metro oder Toei Subway nennen, die mit der Farbe der versenkten Kugel übereinstimmt.

## Spielanleitung

### 1. Grundlegende Spielintegration
* Das Spiel verläuft wie beim Standard-Snooker: Eine rote Kugel versenken, dann eine farbige, und so weiter.
* Nachdem jede farbige Kugel versenkt wurde, muss der Spieler sofort eine Station in Tokio nennen, die gemäß den untenstehenden Regeln der/den zugewiesenen Linie(n) der Farbe entspricht.
* Stationen können nur einmal pro Spiel verwendet werden (sofern nicht durch Tiering- oder Joker-Regeln geändert).
  * Eine gültige Station muss auf dem offiziellen U-Bahn-Plan von Tokio verzeichnet sein und den Farbregeln entsprechen.
  * Spieler haben **10 Sekunden** Zeit, nach dem Versenken einer Farbe eine Station zu nennen; ein Versäumnis führt zum Verlust der Punkte für diesen Stoß und zum Ende ihres Zuges.

### 2. Farb-zu-Linien-Zuweisungen
| Kugelfarbe | Linien |
| :--- | :--- |
| **Rot** | Marunouchi, Oedo |
| **Gelb** | Ginza, Yurakucho |
| **Grün** | Chiyoda, Shinjuku |
| **Braun** | Fukutoshin, Hibiya |
| **Blau** | Tozai, Mita |
| **Pink** | Asakusa, Hanzomon |
| **Schwarz** | Namboku |

* **Umsteigestationen:** Stationen, die mehrere Linien bedienen, können für *jede* ihrer zugehörigen Linien zählen, vorausgesetzt, die Linie stimmt mit der versenkten Farbe überein.

### 3. Erweiterte Optionen
* **Yamanote-Joker-Funktion:**
  * Einmal pro Spiel können Sie eine Station der Yamanote-Linie nennen, um eine zuvor verwendete Station freizuschalten.

## Nutzung der Tracker-App
Gleiche Nutzung wie bei der Standard-Snooker-Tubey-App. Lokal über Node.js auf Port 3000 ausführen.
