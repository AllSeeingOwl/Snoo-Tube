# Comment jouer à Tokyo Snooker & Utiliser l'application Tracker

## Qu'est-ce que Tokyo Snooker ?
Tokyo Snooker est une variante du snooker traditionnel, qui combine l'habileté au tir avec la connaissance géographique du réseau de transport emblématique de Tokyo. Les joueurs doivent annoncer une station valide du Tokyo Metro ou du métro Toei qui correspond à la couleur de la bille empochée, en se basant sur le plan officiel du métro de Tokyo.

## Comment jouer

### 1. Intégration de base au gameplay
* Le jeu se déroule comme au snooker standard : empocher une rouge, puis une couleur, et ainsi de suite.
* Après avoir empoché chaque bille de couleur, le joueur doit immédiatement annoncer une station de Tokyo qui correspond à la ou aux lignes attribuées à la couleur selon les règles ci-dessous.
* Les stations ne peuvent être utilisées qu'une seule fois par partie (sauf si modifiées par les règles de Niveaux ou le Joker).
  * Une station valide doit figurer sur le plan officiel du métro de Tokyo et respecter les règles de couleur.
  * Les joueurs ont **10 secondes** pour annoncer une station après avoir empoché une couleur ; un échec entraîne la perte des points de ce tir et la fin de leur tour.

### 2. Correspondance Couleurs - Lignes
| Couleur de la Bille | Lignes |
| :--- | :--- |
| **Rouge** | Marunouchi, Oedo |
| **Jaune** | Ginza, Yurakucho |
| **Verte** | Chiyoda, Shinjuku |
| **Marron** | Fukutoshin, Hibiya |
| **Bleue** | Tozai, Mita |
| **Rose** | Asakusa, Hanzomon |
| **Noire** | Namboku |

* **Correspondances :** Les stations desservant plusieurs lignes peuvent compter pour *n'importe laquelle* de leurs lignes associées, à condition que la ligne corresponde à la couleur empochée.

### 3. Options Avancées
* **Joker Ligne Yamanote :**
  * Une fois par partie, vous pouvez annoncer une station de la ligne Yamanote pour débloquer une station précédemment utilisée.

## Comment utiliser l'application Tracker
Même utilisation que l'application standard Snooker Tubey. Exécutez-la localement via Node.js sur le port 3000.
