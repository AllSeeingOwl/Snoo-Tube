# 如何游玩东京斯诺克及使用追踪器应用

## 什么是东京斯诺克？
东京斯诺克是传统斯诺克的变体，它将击球技巧与对东京标志性交通网络地理知识的了解结合在一起。玩家必须根据官方东京地铁图，报出一个符合所击落彩球颜色的有效东京地铁或都营地铁站点。

## 如何游玩

### 1. 基本玩法结合
* 按照标准斯诺克规则进行游戏：击落一颗红球，然后击落一颗彩球，以此类推。
* 在每颗彩球落袋后，玩家必须根据以下规则，立即报出一个符合该颜色所分配线路的东京地铁站名。
* 每个站点在每局游戏中只能使用一次（除非被分级或百搭牌规则修改）。
  * 有效的站点必须在官方东京地铁图上，并且符合颜色规则。
  * 玩家在击落彩球后有 **10 秒钟**的时间报出站点；若超时未报，则取消该次击球的得分并结束其回合。

### 2. 颜色与线路对应关系
| 球体颜色 | 线路 |
| :--- | :--- |
| **红色** | 丸之内线, 大江户线 |
| **黄色** | 银座线, 有乐町线 |
| **绿色** | 千代田线, 新宿线 |
| **棕色** | 副都心线, 日比谷线 |
| **蓝色** | 东西线, 三田线 |
| **粉色** | 浅草线, 半藏门线 |
| **黑色** | 南北线 |

* **换乘站:** 服务多条线路的站点可以被计为与其相关的*任何*线路，前提是该线路与所击落的颜色相匹配。

### 3. 进阶选项
* **山手线百搭牌功能:**
  * 每局游戏一次，您可以报出一个山手线上的站点，以解锁一个之前已使用过的站点。

## 如何使用追踪器应用
使用方法与标准 Snooker Tubey 应用相同。通过 Node.js 在本地 3000 端口运行。
