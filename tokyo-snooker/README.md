# How to Play Tokyo Snooker & Use the Tracker App

## What is Tokyo Snooker?
Tokyo Snooker is a twist on traditional snooker, combining cue skill with geographic knowledge of Tokyo's iconic transport network. Players must call out a valid Tokyo Metro or Toei Subway station that corresponds with the colour of the ball potted, based on the official Tokyo Subway map.

## How to Play

### 1. Basic Gameplay Integration
* Play proceeds as in standard snooker: pot a red, then a colour, repeat.
* After each coloured ball is potted, the player must immediately call out a Tokyo station that matches the colour's assigned line(s) according to the rules below.
* Stations can only be used once per game (unless modified by Tiering or Wildcard rules).
  * A valid station must be on the official Tokyo Subway map and match the colour rules.
  * Players have **10 seconds** to call a station after potting a colour; failure results in a forfeit of that shot's points and the end of their turn.

### 2. Colour-to-Line Assignments
| Ball Colour | Lines |
| :--- | :--- |
| **Red** | Marunouchi, Oedo |
| **Yellow** | Ginza, Yurakucho |
| **Green** | Chiyoda, Shinjuku |
| **Brown** | Fukutoshin, Hibiya |
| **Blue** | Tozai, Mita |
| **Pink** | Asakusa, Hanzomon |
| **Black** | Namboku |

* **Interchanges:** Stations serving multiple lines can count for *any* of their associated lines, provided the line matches the colour potted.

### 3. Advanced Options
* **Yamanote Wildcard Feature:**
  * Once per game, you may call a station on the Yamanote line to unlock a previously used station.

## How to Use the Tracker App
Same usage as the standard Snooker Tubey app. Run locally via Node.js on port 3000.
