# 東京スヌーカーの遊び方とトラッカーアプリの使い方

## 東京スヌーカーとは？
東京スヌーカーは、伝統的なスヌーカーに、東京の象徴的な交通機関ネットワークの地理的知識を組み合わせたユニークなゲームです。プレイヤーは、公式の東京地下鉄路線図に基づき、ポケットに入れたボールの色に対応する有効な東京メトロまたは都営地下鉄の駅名を宣言する必要があります。

## 遊び方

### 1. 基本的なゲームプレイ
* 標準的なスヌーカーと同じようにプレイします。赤いボールをポケットに入れ、次にカラーボールを入れ、これを繰り返します。
* カラーボールをポケットに入れた後、プレイヤーは以下のルールに従って、その色に割り当てられた路線に一致する東京の駅名をすぐに宣言しなければなりません。
* 各駅は1ゲームにつき1回のみ使用可能です（ティアリングやワイルドルールで変更されない限り）。
  * 有効な駅は、公式の東京地下鉄路線図に掲載されており、色のルールに一致する必要があります。
  * プレイヤーはカラーボールをポケットに入れてから**10秒以内**に駅名を宣言する必要があります。失敗すると、そのショットのポイントは没収され、ターンは終了します。

### 2. 色と路線の割り当て
| ボールの色 | 路線 |
| :--- | :--- |
| **赤** | 丸ノ内線, 大江戸線 |
| **黄** | 銀座線, 有楽町線 |
| **緑** | 千代田線, 新宿線 |
| **茶** | 副都心線, 日比谷線 |
| **青** | 東西線, 三田線 |
| **ピンク** | 浅草線, 半蔵門線 |
| **黒** | 南北線 |

* **乗換駅:** 複数の路線が乗り入れる駅は、ポケットに入れた色と路線が一致していれば、その駅が関連する「どの」路線としてカウントしても構いません。

### 3. 高度なオプション
* **山手線ワイルドカード機能:**
  * 1ゲームにつき1回、山手線の駅を宣言することで、以前に使用された駅をアンロックして再利用可能にすることができます。

## トラッカーアプリの使い方
標準のSnooker Tubeyアプリと同じ使い方です。Node.jsを使用してローカルのポート3000で実行します。
